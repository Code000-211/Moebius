# Moebius 0.21.0

Still an early prototype: use it only with throwaway repositories and with model accounts whose spending you watch.
Its contracts may change in any later release without a way to migrate.

This release takes four clicks out of the owner's day in the software factory: large source files are reviewed, anyone
may measure, notes merge without a measurement, and a person can move a card.

## The software factory

The settings are in the "Working with others" box and `PUT /v1/repositories/{id}`; the gate is in the
[desktop API](../reference/desktop-api.md#the-merge-gate).

- **Large text files are reviewed as text** (#767). The review context no longer runs git with
  `core.bigFileThreshold=1m`, which made every file over 1 MiB look binary and refused its pull request
  (`it changes the binary file ...`). A file is binary when git finds a NUL byte in it, whatever its size. A large file is
  still given as its part of the diff over `review.file_limit`.
- **Anyone may measure** (#769). `measurers` may hold `*`: a `## Measurement` comment of anyone but the pull request's
  author is read, so a new helper need not be listed first. The author is still refused, and the Reviewer still judges
  the numbers.
- **Notes merge without a measurement** (#773). A new setting, `measurement_free_paths`, holds globs read as
  `locked_paths` are. A change whose merge changes only such paths needs no measurement with `require_measurement` on,
  such as an item closed with its numbers, a measurement record or a design note. One more path and the gate asks for
  the measurement as before.

## Cards

- **A person can move a card** (#771). `POST /v1/cards/{id}/move` (`{column, note?, clear_note?, reason?}`) puts a
  card in another column of its board, which only the column scripts did before.
  - The move keeps, replaces or clears the card's note.
  - It is recorded as `move_card`.
  - It is a fresh start as a retry is: earlier runs stop counting, a stopped run no longer holds the card, and its
    `stuck` item is resolved.
  - The new column's script takes the card up, and a `lane = true` column queues the test lane.
  - It is refused for agents and scripts (403), while a run of the card is going (409), and for a column the board does
    not have (422).
  - The web app has no move action yet.

## Upgrading

The store gets one new column, `repositories.measurement_free_paths`, when the server starts. Nothing else changes for an
existing server.
