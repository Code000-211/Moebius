# Moebius 0.1.1

Still an early prototype: use it only with throwaway repositories and with model accounts whose spending you watch.

## What changed since 0.1.0

- **The project page works in tabs.** Board, plus any number of editors, terminals in the project's clone and agent
  chats in the project, opened from the menu the `+` beside the tabs drops down (a browser tab comes later). The project's files are a
  sidebar on the right; a click on a file opens it in an editor tab at once.
- **Chats are marked only when they need you.** A chat whose agent has answered has no "Waiting" tag any more; one
  whose agent asks you a question is marked "Asks you", in the chat list, the chat and the Fleet.
- **Terminal beside Send.** A started chat has its Terminal button beside Send, as a new chat has, and "Chat" under the
  terminal goes back.
- A release can now be published by starting the release workflow by hand.

## Downloads

As in 0.1.0: the server and command line (`moebius-0.1.1-x86_64-unknown-linux-gnu.tar.gz`), the desktop app for Linux
(`moebius-desktop-0.1.1-x86_64-unknown-linux-gnu.tar.gz`), the app and command line for Windows
(`moebius-windows-x86_64.zip`), the server's program alone for the app's SSH install
(`moebius-x86_64-unknown-linux-gnu`) and `SHA256SUMS`. How to install and check them:
[Running Moebius](https://github.com/Code000-211/Moebius/blob/main/docs/guide/running-moebius.md).
