# Moebius 0.18.0

Still an early prototype: use it only with throwaway repositories and with model accounts whose spending you watch.
Its contracts may change in any later release without a way to migrate.

This release makes the wiki work on every server from the start, and lets its pages be sorted and found from their
project.

## The wiki works without setting it up

- **No `[wiki]` needed** ([ADR 0026](../adr/0026-the-wiki-works-before-it-has-a-remote.md)): without `[wiki] url` the
  server keeps the wiki in a git repository of its own at `<data_dir>/wiki`, made at the first start. Pages, moves,
  history, templates and proposals all work; edits are commits and nothing is pushed. Before, every wiki route answered
  `409` and nobody could write a page.
- **Use a git repository…**: an owner connects one from the Wiki page, Settings > Server > General or Get started,
  without a restart (`GET /v1/wiki/status`, `PUT /v1/wiki/repository`). An empty repository gets the history pushed; one
  with pages is taken when the wiki has none, or when this wiki's history continues it; when both have pages of their
  own the server refuses and merges nothing. If `moebius.toml` cannot be written, the connection is undone.
- **A `url` that cannot be used no longer stops the server**: it starts without a wiki and says why on the Wiki page and
  in Get started. `wiki.url` is a settings key that needs a restart.

## Categories, labels and a project Wiki tab

- **Categories** are folders: "New page" and "Move" have a Category picker with "+ New category", and the tree shows how
  many pages each holds.
- **Labels**: a page has any number, kept in its file as front matter (`labels: [Runbook, On call]`). They are set with
  chips on the page (`PUT /v1/wiki/labels/{*path}`), filter the tree with chips above it, and are found by search. The
  editor shows only the text and writes the front matter back unchanged; a page that starts with a rule is not mistaken
  for one with front matter.
- **A project's Wiki tab** after Milestones (`/projects/<id>/wiki`) shows only that project's pages, with their
  categories and labels; "New page" there makes the page in the project. The sidebar's Wiki still shows them all.

## Upgrading from 0.17

Replace the server and the desktop app: the app and the server must share a minor version, so install the 0.18 app with
the 0.18 server. A server whose `moebius.toml` has `[wiki] url` keeps using it as before. A clone in `<data_dir>/wiki` of
a `url` you removed is used as a local wiki; connecting the same repository again later is accepted.
