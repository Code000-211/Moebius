# Moebius 0.1.6

Still an early prototype: use it only with throwaway repositories and with model accounts whose spending you watch.

## What changed since 0.1.5

- **Adding a provider works after `moebius.toml` changed.** "Log in to a provider" put the new upstream after the
  upstreams the server runs with. When the file had been changed by other means since the server started, it had
  fewer, and the save was refused with "router.upstreams.3: the list has 1 entries, so the next is 1". The new
  upstream now goes after the upstreams of the file.
