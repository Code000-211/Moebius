# Moebius 0.18.4

Still an early prototype: use it only with throwaway repositories and with model accounts whose spending you watch.
Its contracts may change in any later release without a way to migrate.

This release lets a project add its own board columns, each with its own script
([ADR 0030](../adr/0030-custom-board-columns-per-project.md), and the guide [Custom columns](../guide/custom-columns.md)).

## Custom board columns

- **A project adds columns** in `projects/<project>/kanban.toml` of the harness configuration repository: each
  `[[column]]` has a `name`, a `script` beside the file, an `after` (a built-in or custom column) and a `counts_as`
  (one of the six built-in columns, the one before it by default). A column sits anywhere after Backlog and before
  Done; the six built-in columns stay and cannot be renamed.
- **Built-in rules follow a column's class**: a card in "Ready for testing" (counts as In review) counts as in review
  for merges, round limits, external reviews, blockers, analytics, cycles and milestones. Entering a Done-like custom
  column does not close the issue unless its script does.
- **Scripts** see `card.column_class`; `moebius.move` and `check-script --column` (with `--project` or `--kanban`)
  take the custom names.
- **The board, the List view, All issues, views, the snapshot (`columns` per board), `moebius board` and the
  project's Columns tab** show the custom columns in order. `GET`, `PUT` and `DELETE /v1/projects/{id}/columns`
  read and write the file.
- **A column that still holds cards cannot be removed**; the refusal names the cards. A file that changed outside
  Moebius and left cards in a column it no longer has runs them with the script of their class and says so. A card
  moved to a project without its column goes to the built-in column of its class.

## Known limits

- A script cannot read an issue's comments yet, so a column that waits for a measurement reads it from the issue's
  body.
- A view's `columns` filter matches a card's own column name: "In review" does not include a custom column that counts
  as it.

## Upgrading from 0.18.3

Replace the server and the desktop app; nothing else needs doing. A project without `kanban.toml` has the same six
columns as before. Any 0.18 app works with any 0.18 server.

**Full Changelog:** https://github.com/Code000-211/Moebius/compare/v0.18.3...v0.18.4
