# Moebius 0.9.2

Still an early prototype: use it only with throwaway repositories and with model accounts whose spending you watch.

## What changed since 0.9.1

- **The lens is gone** (#213): the lint and type feedback after an agent's own edits, the deep check, the
  `moebius-lens` Pi extension, the `[lens]` table, a project's `lint.toml`, the lens's switch on the Plugins page and
  its box on the Usage page. A `moebius.toml` that still has a `[lens]` table starts as before: the table is ignored,
  and the server says once at the start that it can be deleted. A `lint.toml` left in the harness configuration
  repository is ignored, and the judgements the lens recorded stay readable.

## Downloads

The Linux server as a program and as a `.tar.gz`, `moebius-windows-x86_64.zip` with `moebius.exe`, and `SHA256SUMS`.
How to install and check them: [Running Moebius](https://github.com/Code000-211/Moebius/blob/main/docs/guide/running-moebius.md).
