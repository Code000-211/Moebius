# Moebius 0.5.0

Still an early prototype: use it only with throwaway repositories and with model accounts whose spending you watch.

## What changed since 0.4.0

All of it in the web app and the server; the desktop app has no new screens.

- **Runs work with a sandbox launcher.** With a launcher plugin such as `nono-sandbox`, every run failed before its
  agent answered: the agent directory, where Pi-Bolt keeps its credential store, was granted read only, and the
  sessions directory did not exist yet when the sandbox was made. A run now writes its own agent directory, and the
  sessions and temporary directories are made before the launcher is called (#187, contributed by xzanomad).
- **The chats stand in a column beside the chat** instead of a list that dropped down over it. The column can be
  hidden, and the choice is kept per browser; on a narrow screen it starts hidden and closes when a chat is chosen.
  Each row has its own Delete. A failure the conversation has gone past is no longer drawn again, and a chat whose
  agent went away no longer says so: the next message starts the agent again in the same chat (#188, contributed by
  meeow).
- **A Retro that failed can run again**, from the banner that says why, or with `POST /v1/retros/{date}/retry`
  (#189, contributed by meeow).
- Danger and warning buttons keep their contrast under the pointer, and the card drawer on the board takes its own
  column from a narrower screen on.
- The README shows the web app.
