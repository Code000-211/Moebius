# Moebius 0.17.3

Still an early prototype: use it only with throwaway repositories and with model accounts whose spending you watch.
Its contracts may change in any later release without a way to migrate.

This release fixes the window buttons that went missing at some widths, and text on the dark code boxes that could
not be read.

## Fixed

- **A project's header ran under the window buttons** of the desktop app at some window widths (about 1000 to
  1060 px with the sidebar, 700 to 840 px without it), so Minimize, Maximize and Close looked gone. A header kept to
  one row now measures its room: first its primary button keeps only its icon ("New issue" becomes "+", named in its
  tooltip), then the tabs that do not fit move, from the right, into a last tab "More". The title is cut short and
  never covers the tabs. This holds for every one-row header: projects, agents and milestones.
- **The command and output of a step** in a chat, and diffs in chats, on the diff page, in a card's script preview,
  the script editor and the Retro, were dark text on the dark code box in the light theme. Everything on those boxes
  (text, rules, Copy buttons, notes, the "Blocked" line, the added and removed lines) now uses the code colours, in
  both themes.
- The thin line that joins the steps of a turn no longer runs through an opened step's box.

## Upgrading from 0.17.2

Replace the server and the desktop app; nothing else needs doing. The app and the server must share a minor version,
so any 0.17 app works with any 0.17 server.

**Full Changelog:** https://github.com/Code000-211/Moebius/compare/v0.17.2...v0.17.3

`moebius-desktop-0.17.3-x86_64.AppImage` and `moebius-desktop-0.17.3-amd64.deb` for Linux and
`moebius-desktop-0.17.3-x86_64-setup.exe` for Windows, and `SHA256SUMS`. How to install and check them:
[Running Moebius](https://github.com/Code000-211/Moebius/blob/main/docs/guide/running-moebius.md) and
