# Moebius 0.4.0

Still an early prototype: use it only with throwaway repositories and with model accounts whose spending you watch.

## What changed since 0.3.0

All of it in the web app and the server; the desktop app has no new screens.

- **A menu on every card** (⋯ on the board and in the dock) with Block, Unblock and Delete (#183). A blocked card is
  held where it is: its runs are stopped, column scripts skip it (`card.held`), and the board shows it as Blocked with
  the reason, and the status filter can show only those. Deleting a card is for a person only; its issue on the forge
  stays, and polling does not bring the card back. New routes `POST /v1/cards/{id}/block`, `/unblock` and
  `DELETE /v1/cards/{id}`, and the event `card_deleted`.
- **A built-in Coder and Reviewer** (#184), each with its own instructions and the engineering skills that fit it. The
  Reviewer is the board's review agent. A new agent starts blank or as a copy of any existing agent, which takes over
  everything: model, settings, skills, extensions and instructions. Which engineering skills an agent gets can be
  chosen per agent (`engineering_skills`).
- **Delete buttons wherever something can be deleted** (#185): chats, research briefs, grillings, exports and
  replays; anything still running is stopped first. Deleting stays with a person. New events `chat_deleted`,
  `research_deleted`, `grilling_deleted`, `export_deleted` and `replay_deleted`.
- **A research budget in experiments or in tokens** (#186): a brief says how many experiments may be measured against
  the baseline, or how many tokens its runs may use. Briefs from before are read as a budget in tokens.
- **A chat whose agent failed in the middle of an answer** is taken up again by the next message, in the same chat; an
  empty message asks the agent to answer again (#182, contributed by meeow).
- **The dock names the worktree a card's change is being made in**, while that run is going (#180, contributed by
  meeow).
- The floating chat marks an answer read reliably, also when the answer arrives right after the chat was started.
