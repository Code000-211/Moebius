# Moebius 0.1.5

Still an early prototype: use it only with throwaway repositories and with model accounts whose spending you watch.

## What changed since 0.1.4

- **Logging in to a Claude subscription works.** Anthropic's login page refused the login of the `anthropic` preset
  with "Authorization failed: Invalid request format": the login's `state` was 16 random bytes, and the page takes
  only a longer one. A code login now sends 32 bytes, as Claude Code does. When the server runs on another computer
  than the browser, the browser ends on a `localhost` page it cannot reach: paste that page's address into the app and
  choose "Finish login".
