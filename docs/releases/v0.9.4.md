# Moebius 0.9.4

Still an early prototype: use it only with throwaway repositories and with model accounts whose spending you watch.

## What changed since 0.9.3

- **The settings for shortening tool outputs are gone.** The table `[agents.<name>.tool_output]` (`max_lines`,
  `max_bytes`, `compress`), the options `--output-lines`, `--output-bytes` and `--no-compress` of `moebius agent save`,
  the fields in the agent editor and the saving shown on the Usage page are removed. Old files with the table still
  load; it is ignored and never written.
- **The endpoint `POST /moebius/result` and the code that cut and compressed results are removed.** Moebius changes
  nothing of what a tool prints; the bridge only offers the tool `lessons`. `POST /moebius/check` stays for Claude
  Code and the MCP gateway.

## Downloads

The Linux server as a program and as a `.tar.gz`, `moebius-windows-x86_64.zip` with `moebius.exe`, and `SHA256SUMS`.
