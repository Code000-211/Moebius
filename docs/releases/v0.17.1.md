# Moebius 0.17.1

Still an early prototype: use it only with throwaway repositories and with model accounts whose spending you watch.
Its contracts may change in any later release without a way to migrate.

This release closes the known gaps of 0.17.0.

## Changed

- **Settings and a project's settings** have an icon before each entry of their sub-navigation and no search field,
  as in the approved mockups (`docs/design/navigation/ia3.png`, `ia4.png`).
- **A project's header stays one row** down to the narrow breakpoint: below about 1000 px the quiet buttons (Filter,
  Display, Moebius) keep only their icon instead of wrapping the header.
- **Wrap long lines** in Settings > Appearance, kept per person (`wrap_long_lines` in `/v1/preferences`, off by
  default): code blocks and long lines in chat answers, card threads and run pages wrap instead of scrolling sideways.
  A Density setting is no longer planned and left the design standard.
- **A scheduled workflow shows when it fires next and last fired** in the project's Workflows tab, automation or not
  (`next_firing` and `last_fired` on the project workflow routes).
- **A webhook workflow shows its address** under `/api/hooks/projects/<project>/` on its row, with Copy
  (`hook_address` on the project workflow routes).

## Fixed

- The thin second line under the header of Agents, Skills, MCP servers, Lessons, Experiments and Views is gone.

## Known gaps

- At 800 px the header of the Skills and MCP servers pages still wraps to two rows, because of its hint text.

## Upgrading from 0.17.0

Replace the server and the desktop app; nothing else needs doing. The app and the server must share a minor version,
so a 0.17.0 app works with a 0.17.1 server and the other way round.

**Full Changelog:** https://github.com/Code000-211/Moebius/compare/v0.17.0...v0.17.1
