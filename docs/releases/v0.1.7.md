# Moebius 0.1.7

Still an early prototype: use it only with throwaway repositories and with model accounts whose spending you watch.

## What changed since 0.1.6

- **Copy and paste work in a Wayland session.** On Linux under Wayland the desktop app could not reach the clipboard:
  nothing could be copied or pasted, in a field or anywhere else. The app now opens its window through XWayland when
  the session has it.
- **Select, copy and paste in the terminals.** In the shell of a run, the Terminal page, a project's terminal tab and
  Pi's terminal of a chat: drag with the mouse to select, which copies when the button is released (and again with
  Ctrl+Shift+C); Ctrl+Shift+V or a right click pastes. A pasted line ending does not run the line when the program
  asked for bracketed pastes.
- **Copy buttons.** An answer of the agent (as its Markdown), a code block or a written file, all of what a tool
  printed, and an error's message each have a "Copy" button, since the app's text cannot be selected with the mouse.
