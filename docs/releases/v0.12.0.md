# Moebius 0.12.0

Still an early prototype: use it only with throwaway repositories and with model accounts whose spending you watch.
Its contracts may change in any later release without a way to migrate.

## The sidebar keeps one calm order

In the wide sidebar, Projects and Improve now sit above the chat list instead of below it, so the navigation rows and
the work they lead to come before the conversations. The Projects group collapses like the others; the browser keeps
the state under `moebius.sidebar.group.projects`. The collapsed rail never collapses it, all rows stay. The New chat control is a bare
`+` beside the project filter, and the filter's trigger is bare as well, so the row reads as one tool row; the
accessible names keep their words. The Settings entry at the foot is a gear only and is visible on every page, on the
setting pages included, with the word Settings in the tooltip and the accessible name.

## The conversation reads wider, and the state chip sits beside Send

The measure that capped the conversation to a prose column is gone: messages, thinking blocks, todo lists, the
question card and the skeletons take the width the chat has. The state chip is drawn as a steady secondary control in
the composer's footer beside Send — its text takes the text colour in both themes — and its panel opens over the
composer; in the terminal view, where there is no composer, it stays the floating chip bottom right. The panel's open
state belongs to the page now, so switching between chat and terminal leaves it open.

## Code is coloured by real grammars

A shared source, `web/src/ui/code/`, carries one palette built from the theme's code tokens — 4.5 to 1 contrast on the
code ground in both themes — as CSS classes for static blocks and as a live highlight style for editors, so a keyword,
a string and a number look the same wherever code is drawn. Chat code blocks are drawn from real grammars: Rust,
TypeScript and JavaScript, Python, JSON, C, C++, CSS, HTML and Markdown as Lezer grammars, and the legacy modes for
Luau (by Lua), TOML, YAML, Shell, Dockerfile, Diff, SQL, Ruby, Swift, Go and Java; unknown language names stay plain.
The code editor and the code block share it, the inbox's diffs now colour in their own green and red, the workflow
page's code follows, and `rehype-highlight` is gone from both the packages and the Markdown path. The grammars load
as their own lazy chunk, so the main bundle does not grow.

## The web end-to-end suite is green on main again

The failing chat test of 0.11.0's web app is fixed; the suite runs against the fresh build (#299).
