# Moebius 0.1.2

Still an early prototype: use it only with throwaway repositories and with model accounts whose spending you watch.

## What changed since 0.1.1

- **Log in to a model provider from the app.** On the Models page, "Log in to a provider" picks Anthropic (Claude
  Pro/Max), OpenAI (ChatGPT/Codex) or another provider, adds the upstream while the server runs, opens the provider's
  page in the browser, and takes the code or the address the browser ended on, so it works when the server runs on
  another machine. The presets use the same client ids as Pi, which are other apps' (Claude Code's, the Codex CLI's):
  a provider may block an account for that, and the app says so before every login.
- Anthropic subscriptions are served in full. An OpenAI subscription logs in, but its requests are not served yet: the
  router does not speak the protocol the ChatGPT subscription needs (coming in a later release).
- `[router.upstreams.oauth] preset = "anthropic"` or `"openai"` in `moebius.toml` does the same by hand.
