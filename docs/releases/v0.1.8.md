# Moebius 0.1.8

Still an early prototype: use it only with throwaway repositories and with model accounts whose spending you watch.

## What changed since 0.1.7

- **The agent list of a new chat is no longer empty on a fresh server.** After `moebius init`, with no
  `[agents.Coder]`, the Moebius agent and the Grilling partner had no model and were left out, so the list was empty.
  They are now always offered. A new chat with one of them says that it has no model yet; choose one in the chat's
  Model field, or give the Coder a model on the Agents page, and the chat starts.
