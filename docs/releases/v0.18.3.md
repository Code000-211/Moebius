# Moebius 0.18.3

Still an early prototype: use it only with throwaway repositories and with model accounts whose spending you watch.
Its contracts may change in any later release without a way to migrate.

This release reviews a helper's pull request when they say it is done, and merges it when the Reviewer approves
([ADR 0029](../adr/0029-the-reviewer-reads-a-pull-request-when-its-author-says-done.md), and the guide
[Working with others](../guide/working-with-others.md)).

## Review on `/done`

- **When the author of a followed pull request writes `/done` on its issue**, the Reviewer reads it once the checks of
  its current head have passed (a repository with no checks is read at once; red checks get a reply and no review).
- **Changes requested** become a real review on the forge, with comments on the lines they are about. The card shows
  the same review, and waits for the author's changes; a new `/done` after a push starts the next round.
- **An approval is merged** when **Merge external pull requests the reviewer approves** is on (the default, in the
  repository's "Working with others" box): an approving review, a merge pinned to the head and the base that were read,
  "Merged, thank you @alice!" on the issue, and the card is done. With it off, the card goes to Ready to merge and you
  decide. Before it merges, the server reads the pull request's base again and makes sure the merge into the current
  tip of the default branch has the same effect as the one that was reviewed; Hold, Pause all and the setting are
  checked right before the merge.
- **At most three rounds per pull request**, counted across closing and reopening it, one at a time; after that a
  person decides. A round that hangs is ended on its own, and **End this review round** on the card ends one by hand.
  While a round is going, the card offers no merge.

## A stranger's code is data

- The review of an outside pull request runs **without tools and without a checkout**: the server builds what the
  Reviewer reads from git objects alone (the diff of the merge into the base, and the whole changed files), with every
  git step checked, bounded in time and memory, and never running the repository's filters or hooks.
- **What does not fit whole is not reviewed automatically**: more than 60 files, a diff over 60 KB, a file over 40 KB,
  150 KB in all, a binary file, or a path that is not valid UTF-8 gets a reply and an Inbox item for you instead.
- The run gets no wiki pages, lessons or comments, starts in a fresh private directory, and its tool calls are refused
  by the router whatever the harness does; everything it posts is redacted first.

## Upgrading from 0.18.2

Replace the server and the desktop app; the store gains the new tables and fields when the server starts. Reviews
start only when a helper writes `/done` on an issue whose pull request is followed. Any 0.18 app works with any 0.18
server.

**Full Changelog:** https://github.com/Code000-211/Moebius/compare/v0.18.2...v0.18.3
