# Moebius 0.11.0

Still an early prototype: use it only with throwaway repositories and with model accounts whose spending you watch.
Its contracts may change in any later release without a way to migrate.

## The chats live in the sidebar

The wide sidebar lists the conversations in place, grouped under Today, Yesterday and Older, with an unread dot and
the active chat highlighted, so a person reads what is new without opening the chat page (#284). The list is filtered
by project (#285) and has a search field beside the New chat button (#286). The separate Chat navigation row is gone
from the wide sidebar; the collapsed rail keeps its single Chat icon, leading to the most recent chat, unread trail
included (#290).

## A chat takes the page's full width

The chat page's middle column is gone: the conversation takes the width the page has, and the top bar keeps only the
title (#288). The chat's actions hold an always-visible chip at the bottom right of the conversation — a small button
that says the chat's state in one word and opens, on click, the panel with every action: the terminal, offering what
the worktree changed, publishing and ending a grilling, stopping the agent, the model and reasoning choices, and
Rename and Delete (#289).

## A review can open the change's pull request itself

The new bridge function `moebius.open_pull_request()` publishes the card's change and, when it has no pull request
yet, opens it at once, so a forge's checks can run on the pull request while the review still reads the change. The
poll reads the checks of the pull request's head commit, and the script offers the change only when they are green;
red checks return the card to *In progress* with "The checks failed:". It does nothing beyond the publish on a forge
without pull requests, and nothing at all when the commit already has one, so a script may call it on every tick.
[The column scripts reference](https://github.com/Code000-211/Moebius/blob/main/docs/reference/column-scripts.md) has
the contract.

## Grilling asks through the question picker

The built-in grilling partner now asks every question through the `ask_user_question` tool: the chat shows it as a
picker the person clicks, one question at a time, never as chat prose, and the answering agent ends its turn after
each call, so the grilling waits for the answer in the person's next message.
