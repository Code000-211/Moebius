# Moebius 0.1.4

Still an early prototype: use it only with throwaway repositories and with model accounts whose spending you watch.

## What changed since 0.1.3

- **Chats no longer lag.** A chat with an agent was slow while the agent wrote, worst on Windows: the app told the
  server the chat was read at every streamed piece of an answer and went through the whole conversation each time. It
  now does so once per answer and looks only at what changed.
- **The chat follows the answer.** The conversation scrolls down as the agent writes, unless you scrolled up; sending a
  message follows it again. The same holds in the floating chat window.
- **The app remembers its server.** Connecting by address and token after an SSH connection that was begun and not
  cancelled saved the SSH host instead, so the app asked for the address and token at every start. Connect once more
  after updating and it is kept.
- **Models after a login.** After an OAuth login on the Models page the models the provider serves are listed at once,
  not up to five minutes later.
- **The decision model's models.** The decision model's Model field offers the models its own endpoint lists,
  instead of the router's.
- **The Moebius agent knows where Moebius runs.** Its prompt names the server's program, version, configuration and
  addresses and where the desktop app runs, and where to report a fix to Moebius itself.
- A Projects page shows every repository and can remove one; a model-provider login opens the browser, not a file
  window; the lens runs its deep check once per changed package.
