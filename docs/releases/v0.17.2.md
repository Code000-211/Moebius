# Moebius 0.17.2

Still an early prototype: use it only with throwaway repositories and with model accounts whose spending you watch.
Its contracts may change in any later release without a way to migrate.

This release gives agents, workflows and rules pages that are easy to read and edit.

## Changed

- **An agent has a page of its own** instead of a small window: tabs Settings, Instructions and Extensions, with
  Delete and Save in the header. The instructions are edited in a large light editor. Extensions lists the agent's
  Pi packages and the pi.dev catalog to search and add from, so the narrow Packages panel that covered the desktop
  window's buttons is gone.
- **A workflow has one page** with the tabs Overview, Canvas, Runs and File, and Copy hook URL and Run in the header.
  Overview says the trigger and every step in plain words and lists the last runs; File shows the TOML read-only.
  The old summary with overlapping step cards and raw parameters is gone.
- **The canvas** has a slim "Add a step" palette with one name per kind, and its steps open at a readable size.
- **Rules** has its scopes on the left (Built-in, Server, each repository, Refusals) and the chosen scope's rules on
  the right in full text, with where each applies and how often it refused a call this week.

## Upgrading from 0.17.1

Replace the server and the desktop app; nothing else needs doing. The app and the server must share a minor version,
so any 0.17 app works with any 0.17 server.

**Full Changelog:** https://github.com/Code000-211/Moebius/compare/v0.17.1...v0.17.2

`moebius-desktop-0.17.2-x86_64-setup.exe` for Windows, and `SHA256SUMS`. How to install and check them:
