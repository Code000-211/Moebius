# Moebius 0.18.2

Still an early prototype: use it only with throwaway repositories and with model accounts whose spending you watch.
Its contracts may change in any later release without a way to migrate.

This release lets helpers take your issues without a role on your repository: they comment, and your server assigns
them ([ADR 0028](../adr/0028-helpers-take-issues-with-commands-in-comments.md), and the guide
[Working with others](../guide/working-with-others.md)).

## Commands in issue comments

On GitHub only people with a role (Triage or more) may assign, but anyone who commented on an issue may be assigned.
Turn on **Take issues with /take, /release and /done** in the repository's "Working with others" box, on the server of
the repository's owner, and it reads new comments at each poll:

- **`/take`** assigns the person who wrote it, with the server's own access. It needs an open issue nobody has taken,
  one that carries the ready label when "Mark ready issues" is on, and a login that holds fewer issues than the limit
  (**Issues one login may hold**, 3 by default). Your board shows the card greyed, "Taken by @alice with /take", with
  "Release from @alice".
- **`/release`**, by the assignee, gives the issue back.
- **`/done`**, by the assignee: when a followed pull request closes the issue, the server only answers. Without one you
  get an Inbox item and a question on the card, with the rest of the comment as the reason: "Close the issue", "Give it
  back to @alice" or "Release it". Helpers never close anything themselves.
- **Answer on GitHub** (on by default): the server answers every command, and what you do on the card, with a short
  comment, such as "Assigned to @alice." or "Already taken by @bob.". A command that fails is answered "Could not do
  that: … Try again." and does not stop the ones after it.
- A command is the first word of a line; quoted lines, code blocks, the server's own comments and comments from before
  the setting was turned on are ignored, and each comment is read once. GitLab and Forgejo assign only members and
  collaborators, so others get "Could not assign".

## Upgrading from 0.18.1

Replace the server and the desktop app; the store gains the new fields when the server starts. The commands are off
until you turn them on. Any 0.18 app works with any 0.18 server.

**Full Changelog:** https://github.com/Code000-211/Moebius/compare/v0.18.1...v0.18.2
