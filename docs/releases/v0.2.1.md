# Moebius 0.2.1

Still an early prototype: use it only with throwaway repositories and with model accounts whose spending you watch.

## What changed since 0.2.0

All of it in the web app and the server; the desktop app is unchanged. Contributed by meeow in #174 to #178.

- **A chat whose agent went away carries on.** After a server restart, or when its agent stopped, writing to a chat
  starts an agent again on the same chat, its branch and what was said before, instead of making you start a new one.
  Its model and reasoning level can be changed while it waits. Two messages at once start one agent, and a chat that
  is starting says so.
- **Reasoning levels follow the endpoint.** A model whose endpoint lists its own reasoning level names (the
  `capabilities.reasoning_efforts` of an OpenAI-style `/v1/models`) is sent those names, matched by rank, so the
  hardest level is used rather than quietly lowered. The web app offers only the levels a model takes.
  `[router.model_thinking]` still overrides.
- **Long chats open at their last message** and read older pages as you scroll up, instead of reading the whole
  conversation first.
- **Pages show the shape of what they are loading** instead of a spinner, and fill in place.
- **Smaller things:** a Fleet tile keeps each step on one line, a finished run no longer repeats that it ended, and a
  conversation that cannot be read says why.
