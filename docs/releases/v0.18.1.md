# Moebius 0.18.1

Still an early prototype: use it only with throwaway repositories and with model accounts whose spending you watch.
Its contracts may change in any later release without a way to migrate.

This release lets people who each run their own server work on the same repository, coordinated through the forge
alone ([ADR 0027](../adr/0027-working-with-people-on-other-servers-through-the-forge.md), and the guide
[Working with others](../guide/working-with-others.md)).

## Working with others

- **Taking an issue assigns you on the forge.** Set your login on GitHub (and on GitLab or Forgejo) in Settings >
  Profile. When you take an issue, or the board starts a run for you, your server assigns that login before the run
  starts and reads the assignees back: when two servers take an issue at once, the one listed first keeps it and the
  other starts nothing. Without a login, or when the forge refuses, the run goes ahead and the card says why.
- **An issue someone else is assigned to is left alone**: it stays on your board, greyed, with "Taken by @alice", no
  run starts on it, and a claim is refused. Column scripts see it as `card.taken_by`.
- **"Working with others" per repository** (Project settings > Repositories): **Mark ready issues on <forge>** keeps a
  label (default "Ready for agent") on every open issue that is approved and has no open blocker, and takes it off as
  soon as one appears; turn it on only on the server of the repository's owner. **Agents take** is all approved issues,
  or only issues with that label and no assignee, for a helper's server.
- **A helper's pull request is followed.** A pull request against the default branch, by someone who may write to the
  repository or is the issue's assignee, that closes an issue ("Fixes #n") moves its card to In review with the pull
  request and its checks, and puts an item in the owner's Inbox. The card window offers "Review with agent" and "Merge".
  A review counts only for the head it read, and the merge is pinned to that head and waits for its checks. When the
  pull request is merged the card is done; when it is closed, the card goes back, and a reopened one is followed again.

## Upgrading from 0.18.0

Replace the server and the desktop app; the store gains the new fields when the server starts. Nothing changes until
someone sets a forge login or turns on the settings of "Working with others". The app and the server must share a
minor version, so any 0.18 app works with any 0.18 server.

**Full Changelog:** https://github.com/Code000-211/Moebius/compare/v0.18.0...v0.18.1
