# Moebius 0.1.3

Still an early prototype: use it only with throwaway repositories and with model accounts whose spending you watch.

## What changed since 0.1.2

- **A ChatGPT subscription serves runs.** An upstream logged in with the `openai` preset is now served: the router
  translates the harness's requests to the Responses protocol of the ChatGPT backend's Codex endpoint, as Pi does, and
  the answers back, streamed or not, with tool calls, errors and usage. The tool-call check, usage counting and budgets
  apply as for any upstream. Its models are the eight that Pi lists for a ChatGPT account.
- As in 0.1.2, the presets use other apps' client ids (the Codex CLI's for OpenAI); a provider may block an account for
  that, and the app says so before every login.
