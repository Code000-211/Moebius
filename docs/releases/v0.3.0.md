# Moebius 0.3.0

Still an early prototype: use it only with throwaway repositories and with model accounts whose spending you watch.

## What changed since 0.2.1

All of it in the web app and the server; the desktop app is unchanged.

- **Packages in the web app.** The Plugins page has "Browse packages", which opens a package sheet on the Moebius
  registries, and lists the installed packages with the update that is waiting. An agent's Extensions has "Browse Pi
  packages", which opens it on the pi.dev catalog for that agent. In the sheet you search, filter by kind, read a
  package, and install, update or remove it. A plugin installs at once (a launcher, such as `nono-sandbox`, after a
  restart); a workflow, rules or skills package and every Pi package is a change you merge, and the sheet links to it
  in the Inbox. The sheet and the floating chat share one place at the bottom right: opening one minimises the other.
- **A new event, `extension_update_available`**, when the nightly check finds a newer version of an installed Pi
  package, so the web app shows the update at once.
- **The floating assistant's chats are on the Chat page** and count as unread like any other; the row above a long
  chat's oldest message only offers earlier messages when there are some (#179, contributed by meeow).
