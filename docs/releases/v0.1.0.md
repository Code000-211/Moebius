# Moebius 0.1.0

The first release of Moebius, an orchestration layer that drives coding-agent harnesses from a repository's issues to
changes ready to merge.

**This is an early prototype.** Use it only with throwaway repositories and with model accounts whose spending you
watch. Its contracts (configuration, column scripts, the desktop API, the plugin API) may change in any later release
without a way to migrate.

## What is in it

- **The board.** Issues become cards that move through columns, each column a Luau script. A code run, a review run and
  the merge are steps of the default workflow. A failing reproduction test comes before a fix, and a review looks at
  correctness and at the issue's intent.
- **Harnesses.** Pi-Bolt and Claude Code, picked per agent. Runs can go to another machine over SSH (runners).
- **Every tool call checked.** Patterns, rules in prose, a teacher model, and an optional decision model that learns
  from the judgements, shadows each kind of decision and is proposed to take one over once it agrees well enough. MCP
  calls go through a gateway that checks and logs them.
- **Forges.** GitHub (an App), GitLab, Forgejo and Codeberg, or a plain git repository; polled, and woken by webhooks
  where the forge can reach the server.
- **Better output.** Smaller tool outputs, a lint and type check after each edit, a hint of the files a card is likely
  to touch, lessons from earlier cards, several attempts on a hard card picked by execution, and engineering skills for
  every agent.
- **Improving itself.** A nightly Retro reads the day's failures and proposes changes, which are tried overnight and
  kept only when they do no harm; experiments measure a change against a number.
- **The desktop app.** For Linux and Windows: the board, the live view of a run, chats with the Moebius agent and with
  any agent, terminals, file search, agents, skills, MCP servers, rules, usage and settings. It connects to a server
  directly or over SSH, setting the server up there, and forwards the ports runs and terminals open.

## Downloads

- `moebius-0.1.0-x86_64-unknown-linux-gnu.tar.gz`: the server and command line, with its systemd unit.
- `moebius-desktop-0.1.0-x86_64-unknown-linux-gnu.tar.gz`: the desktop app for Linux.
- `moebius-windows-x86_64.zip`: the desktop app and the command line for Windows.
- `moebius-x86_64-unknown-linux-gnu`: the server's program alone, which the desktop app installs over SSH.
- `SHA256SUMS`: the checksums of all of them.

The server runs on Linux, and on Windows inside WSL 2. Each archive holds `LICENSE` and `NOTICE`. [Running
Moebius](../guide/running-moebius.md) says how to install, check the download and start.

## Known limits

- One person per server; there are no accounts.
- Training a decision model is not part of Moebius; it exports the judgements for that.
- macOS is not built.
