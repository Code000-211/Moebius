# Moebius 0.15.1

Still an early prototype: use it only with throwaway repositories and with model accounts whose spending you watch.
Its contracts may change in any later release without a way to migrate.

This release fixes the desktop app of 0.15.0, whose window could not be resized.

## Fixed

- **The desktop app's window resizes again.** Since 0.15.0 the window holds a page per opened server, and those pages
  covered the edges the window is resized by. Each page now gives the outer 6 px to the window: the pointer shows the
  resize cursor there, and a press drags that edge or corner. It does nothing while the window is maximized. Checked on
  Linux (X11) on all four edges and corners, with and without a server open; on Windows and on Wayland it was built
  but not tried.

## Upgrading from 0.15.0

Install the desktop app of 0.15.1 over the one you have. It works with a server of 0.15.0 or 0.15.1; the server itself
is unchanged but for its version, so upgrading it is not needed.

**Full Changelog:** https://github.com/Code000-211/Moebius/compare/v0.15.0...v0.15.1
