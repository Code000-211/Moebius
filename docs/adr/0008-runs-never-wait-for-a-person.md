# A run never waits for a person

Once a run has started, nothing in it waits for a person: not a broken rule, not an irreversible action, not a question a
harness or one of its extensions asks. A tool call that breaks a rule is not passed on, and the model is told which rule it
broke so that it finds a way that keeps to it; an irreversible action is refused the same way rather than held for approval;
a question from a harness gets an answer from Moebius. The point of Moebius is that work handed over in the morning is done by
the evening, and work that stopped ten minutes in for a question nobody was there to answer is the failure it exists to
prevent. People decide before the work starts (a confirmed set of issues from a grilling, the brief of an autoresearch) and
when it ends (the merge); everything between is the workflow's.

## Consequences

- A rule has to say what is not allowed in a way the model can act on, because the model, not a person, has to find the way
  around it.
- What was refused, and why, is evidence for the Retro.
