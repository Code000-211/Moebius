# Navigation by what you do: approved mockups

The owner approved these mockups for the navigation restructure (issue #690). They are pictures, not the standard;
the decision is written in ADR 0024 and the standard in [`docs/design-web.md`](../../design-web.md).

- `ia1.png`: a project with the tabs Board, Workflows, Cycles and Milestones, and a gear to its settings; the new sidebar.
- `ia2.png`: the project's Workflows tab. The owner later decided that workflows belong to a project, so the
  definitions live in this tab too, not under Build.
- `ia3.png`: the project's settings: General, Members, Repositories, Columns.
- `ia4.png`: Settings with only real settings: You (Profile, Appearance, Keyboard shortcuts, My tokens) and Server
  (General, Models, Plugins, Kinds of issues, Members).
