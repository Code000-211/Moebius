Rules for the runs in this repository. Text before the first heading is ignored.

## no-new-dependencies
Do not add a dependency to Cargo.toml or package.json unless the issue asks for it.

## tests-with-code
A change to behaviour comes with a test for it. Do not delete or skip an existing test to make a run pass.

## leave-ci-alone
Do not edit files under .github/ or any other continuous integration configuration.
